# Código legado

`customtkinter_app.py` conserva la interfaz anterior a Nikaido 2.0 para consultar
comportamientos durante migraciones. No forma parte del arranque, del build ni
de la arquitectura activa.

La interfaz oficial está en `gui/modern_app.py` y `gui/app.py` funciona como
módulo de compatibilidad para integraciones antiguas.
