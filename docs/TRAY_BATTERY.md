# Bandeja inteligente de Nikaido

## Uso

Con la opción **Ajustes → Enviar a la bandeja al minimizar** activa, el botón `−` oculta la ventana y mantiene Nikaido funcionando junto al reloj de Windows.

- **Clic izquierdo:** abrir Nikaido.
- **Clic derecho:** estado, batería, perfil, cambio rápido de perfil y salida.
- **Cerrar (`×`):** finalizar Nikaido por completo.

## Lectura del icono

El pequeño medidor sobre el logo representa el nivel del DualSense:

- verde: más de 45 %;
- amarillo: 21–45 %;
- rojo: 0–20 %;
- cian y rayo: cargando;
- gris con marca roja: desconectado.

El porcentaje exacto aparece al colocar el cursor sobre el icono.

## Nota de Windows

Windows decide si cada icono aparece directamente junto al reloj o dentro del menú `^` de iconos ocultos. El usuario puede arrastrar el icono de Nikaido fuera de ese menú o fijarlo desde la configuración de la barra de tareas.
