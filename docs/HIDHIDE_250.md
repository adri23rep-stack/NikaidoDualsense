# HidHide y doble entrada

La pantalla **Compatibilidad** revisa si un juego puede ver al mismo tiempo el DualSense físico y el control virtual.

Nikaido usa solamente el cliente y el CLI oficiales de HidHide. No modifica el controlador del kernel ni borra configuraciones de otras aplicaciones.

Puede:

- detectar instalación y versión;
- revisar el estado del ocultamiento;
- comprobar si `Nikaido.exe` está permitido;
- listar DualSense detectados por HidHide;
- abrir el cliente oficial;
- iniciar la instalación mediante Windows Package Manager;
- permitir `Nikaido.exe`;
- activar o desactivar el ocultamiento;
- ocultar o volver a mostrar un ID exacto elegido por el usuario.

Ocultar un dispositivo siempre requiere selección y confirmación. Si el CLI devuelve un error, la pantalla recomienda abrir el cliente oficial en lugar de intentar cambios agresivos.
