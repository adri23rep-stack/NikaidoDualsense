# Nikaido DualSense v1.5.0

## Emulación como sección independiente

- Nueva pestaña **Emulación** en la barra lateral.
- Selector visual para Xbox 360, DualShock 4 o sin emulación.
- La emulación ya no está escondida dentro de Herramientas.

## Touchpad como mouse

- Switch directo para activar o desactivar el touchpad como mouse.
- Sensibilidad ajustable entre 0.5 y 8.0.
- El ajuste se guarda en la configuración general.
- La interfaz avisa si Windows o pywin32 no están disponibles.

## Acceso rápido al giroscopio

- Switch de activación desde la página de Emulación.
- Si el gyro no tenía modo configurado, se activa automáticamente en modo mouse.
- Botón directo para abrir Gyro Studio y editar los ajustes avanzados.
