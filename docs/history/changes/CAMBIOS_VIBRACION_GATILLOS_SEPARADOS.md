# Nikaido DualSense 1.2.1 — vibración y gatillos separados

## Cambios de interfaz

- La sección **Vibración** ahora contiene únicamente los motores hápticos, la intensidad guardada por perfil y las pruebas izquierda/derecha.
- Se añadió una sección independiente llamada **Gatillos adaptativos** en la barra lateral.
- Gatillos adaptativos reúne rigidez, efectos, zonas, frecuencia, animaciones, vibración interna de L2/R2 y curvas multizona.
- Ambas páginas tienen accesos cruzados para evitar que usuarios nuevos confundan la vibración general con la resistencia de los gatillos.
- El Dashboard también muestra un acceso directo a Gatillos adaptativos.

## Compatibilidad

No cambia el formato de los perfiles. Los perfiles creados en 1.2.0 siguen funcionando y conservan sus valores de vibración, L2 y R2.
