# Nikaido DualSense 1.6.0

## Calibración guiada
- Nueva pestaña dedicada para calibrar drift de la palanca izquierda y derecha.
- Reutiliza el calibrador promediado de Input Studio sin bloquear la interfaz.
- Acceso directo a calibración del giroscopio.
- Guía para comprobar el recorrido completo de L2 y R2.
- Guarda los ajustes en el perfil activo.

## Curvas visuales
- Editor visual normalizado para las curvas personalizadas de las palancas.
- Cinco puntos, con extremos protegidos y puntos interiores arrastrables.
- Curvas independientes por perfil y por palanca.
- Se conserva el editor visual avanzado de curvas de gatillos.
- Gyro Studio conserva sus curvas de respuesta y telemetría en tiempo real.
