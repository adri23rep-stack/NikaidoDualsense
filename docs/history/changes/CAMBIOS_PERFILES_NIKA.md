# Nikaido DualSense v1.4.0 — Perfiles `.Nika`

Los perfiles exportados ahora usan la extensión propia `.Nika`.

Cada paquete puede incluir:
- Configuración completa de L2 y R2.
- Vibración y giroscopio.
- Luces, animaciones y efectos personalizados.
- Ajustes de Input Studio.
- Imagen del perfil.
- Macros asignadas exclusivamente a ese perfil.

El formato es un paquete comprimido con manifiesto y archivos internos separados. Al importar se generan identificadores nuevos para evitar sobrescribir perfiles o macros existentes. Los perfiles JSON de versiones anteriores siguen siendo compatibles para importación.
