# Nikaido DualSense 2.8.0

Esta versión convierte a Nikaido en una asistente opcional para todo el programa.

## Cambios principales

- Pregunta final al terminar u omitir el wizard.
- Respuesta visual feliz al aceptar y triste al rechazar.
- Consejos contextuales ocasionales dentro de la ventana principal.
- Accesos directos desde cada consejo a la herramienta relacionada.
- Controles en Ajustes para activar la asistente o silenciar sus consejos.
- Panel compacto con carga de sprites a tamaño reducido y liberación explícita de memoria.
