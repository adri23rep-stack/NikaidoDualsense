# Nikaido DualSense 2.9.3 — pulido de primer inicio y batería

## Cambios

- El idioma ahora es la primera pantalla grande del wizard.
- En una configuración nueva, el idioma debe elegirse explícitamente y no puede omitirse.
- La batería ya no aparece como 0 % mientras aún no existe una lectura válida.
- La tarjeta de batería del Dashboard fue rediseñada con porcentaje, estado y barra.
- Los reportes, notas de release, hotfixes y validaciones se movieron a `docs/history/`.
- El nombre del titular legal aparece solamente en la última línea de los textos de licencia visibles.
- Se conservan el asistente global, idiomas, optimizaciones de RAM y pipeline Nuitka protegido.
