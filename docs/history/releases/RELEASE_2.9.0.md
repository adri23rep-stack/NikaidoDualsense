# Nikaido DualSense 2.9.0

## Curva visual de Input Studio

- El selector de curva actualiza la gráfica inmediatamente.
- Lineal usa `y = x`.
- Exponencial usa `y = x²`.
- Agresiva usa `y = √x`.
- La línea punteada muestra la referencia lineal.
- Los puntos solo se editan en **Personalizada**, sin desactivar ni apagar visualmente el gráfico.
- La curva personalizada continúa guardándose por perfil y por palanca.

## Idiomas

Nikaido ahora incluye:

- Español
- English
- Português (Brasil)

El idioma puede elegirse desde el encabezado del wizard y desde **Ajustes → Idioma / Language**. El cambio es inmediato y se conserva en la configuración.

La traducción se aplica a la navegación, títulos, páginas cargadas bajo demanda, pestañas, menús, botones, tooltips, encabezados de tablas, wizard, asistente, Dashboard, Input Studio y mensajes principales. Las páginas nuevas reciben el idioma activo al construirse.

## Compatibilidad

- No cambia el formato `.Nika`.
- No cambia la configuración de perfiles, macros, luces, gyro ni emulación.
- Conserva la optimización de RAM de 2.7.2.
- Conserva el asistente global de 2.8.0.
- El onboarding sube a versión 5 para mostrar el selector de idioma actualizado.
