# Historial de desarrollo de Nikaido

Los documentos que antes llenaban la raíz del proyecto están organizados aquí:

- `releases/`: notas de versiones.
- `hotfixes/`: correcciones puntuales y del pipeline protegido.
- `reports/`: reportes técnicos de implementación.
- `validations/`: resultados históricos de pruebas.
- `changes/`: notas de funciones específicas.
- `roadmaps/`: planes y propuestas anteriores.

Los archivos `.bat` de compilación e instalación permanecen en la raíz para que
sean fáciles de encontrar.
