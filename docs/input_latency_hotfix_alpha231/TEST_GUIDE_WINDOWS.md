# Prueba rápida en Windows

1. Extrae el ZIP completo en una ruta corta.
2. Ejecuta `INICIAR_NIKAIDO.bat`.
3. Conecta el DualSense por USB y activa emulación Xbox o PS4.
4. Mueve ambas palancas con curvas, macros y remapeo desactivados; después repite con tu perfil normal.
5. Activa un efecto RGB y vibración para comprobar que ya no provoquen tirones.
6. Repite por Bluetooth.
7. Abre el Centro de diagnóstico y guarda una captura de las métricas de entrada.

Si todavía se siente retraso, anota si sucede en Xbox, PS4 o ambos; USB, Bluetooth o ambos; y si desaparece al desactivar gyro, macros, curvas o RGB. Esos datos permiten ubicar el siguiente cuello de botella sin adivinar.
